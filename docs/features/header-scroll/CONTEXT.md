# Domain Context — header-scroll

## Glossary

- Divider — the bottom line of the pinned header that separates it from the page content, shown only with the pinned header. NOT a separator between page sections, and NOT a line under the resting header.
- Hidden header — the header is off-screen after 10 px of travel downward, added up in that direction, while the page is below the top. NOT the resting header and NOT the pinned header, both of which stay visible.
- Opening tone — the dark or light pair a page declares once for its header, passed in from that page's route, and kept for the whole page. NOT the background of a later section, and NOT a color read from the pixels on screen.
- Pinned header — the shorter header with a bottom divider and a solid ground in the page's opening tone, shown after an upward move while the page is below the top, and when the page opens already below the top. NOT the resting header, the taller header with no divider and no solid ground shown only when the page is at the very top.
- Resting header — the taller header with no bottom divider and no solid ground, shown when the page is at the very top, including a page that does not scroll and the saved first view of a page. NOT the pinned header, the shorter bar with a divider and a solid ground shown once the page is below the top.

# Design system — julia-site

> The project's **design canon**, produced once per repo by `design-system` and read by
> `ux-flows` / `screens` / `implement` / `review`. Committed — the tool choice and the inventory
> are team-wide, not per-developer. `architecture-map.md` §Frontend / UI foundation stays the
> inventory of the **code**; this file is the **design-side** canon (tool, posture, tokens,
> component inventory, cross-screen conventions). Refresh via `/sdd:design-system` when the
> foundation changes.

## Platform posture

- **Posture:** desktop-first — new screens are drawn at the 1440px frame first. The live CSS already narrows from that width with `max-width` queries (`src/styles/_breakpoints.scss:7-16`). Phone layouts are separate Figma frames the designer supplies; they are not the starting point and they are not guessed from the desktop frame.
- **Breakpoints / device classes:** code thresholds are `$bp-desktop` 1440, `$bp-laptop` 1200, `$bp-tablet` 1024, `$bp-stack` 768, `$bp-narrow` 759, `$bp-compact` 660, `$bp-single` 599, `$bp-phone` 479, `$bp-small` 360, `$bp-mini` 320 (`src/styles/_breakpoints.scss:7-16`). Figma frame widths in the responsive sections are 1440, 1200, 1024, 768, and 390. A new screen uses the `$bp-*` names in code. It does not add a raw 390, 599, or 800 breakpoint.

## Token source

Colors, type, space, and size come from Sass variables. A screen does not declare a new hex or a one-off px value. `@use` order in component SCSS is colors, typography, spacing, sizes (`.cursor/rules/scss-tokens.mdc`).

- **Colors:** Sass variables in `src/styles/_colors.scss:6` — surfaces (`$bg`, `$paper`, `$surface-inverse`), text (`$text`), accent (`$accent`, `$accent-text`, `$accent-hover`). Case brand colors painted by `CasePalette`, `CasePoster`, and `CaseBanner` come from that case's data, not from a new token.
- **Spacing / sizing:** spacing scale in `src/styles/_spacing.scss:5` (`$space-2` through `$space-160`). Geometry in `src/styles/_sizes.scss:5` (`$page-max-width` is 1440px). Width thresholds in `src/styles/_breakpoints.scss:6`.
- **Typography:** families and the size scale in `src/styles/_typography.scss:4` (`$font-family` Min Sans, `$font-size-14` through `$font-size-hero`).

## Interaction & writing conventions

- **Errors:** page-level. An unknown URL or an unknown case id renders `NotFoundPage` (`src/pages/not-found/NotFoundPage.tsx:9`, route `src/App.tsx:28`). Copy is "This page does not exist." with a link "Back to the homepage". No toasts and no inline error slots.
- **Empty states:** none. Project lists come from `src/constants/projects.ts`. A missing page is the 404 above, not an empty grid.
- **Loading:** the case page is lazy, and its Suspense fallback is `null` (`src/App.tsx:16`). No skeleton and no spinner. The prerendered HTML is what the visitor sees first.
- **Validation:** no forms. Contacts are links and a location line (`src/components/Contacts/Contacts.tsx:8`).
- **Microcopy tone:** short, literal English. Chrome strings already in the product: "Skip to content", "Open menu" / "Close menu", "Back to top", "Projects", "Contacts". Page titles use `SITE_OWNER` ("Julia Samchuk") from `src/constants/site.ts:1`.
- **Desktop and phone:** draw the desktop frame first (`Desktop / …`, 1440px). Add the phone frame as its own Figma frame (`390 px` in that screen's section). Do not ask the pipeline to invent the phone layout from the desktop frame.
- **Focus:** the skip link is the keyboard path to `#main-content`. Its focus ring uses `$accent` (`src/index.scss:74`).
- **Images:** WebP under `public/projects/`, produced by the image scripts. A new screen does not embed a PNG or a JPG.
